# AI 引擎日报｜2026-11-17

今天的增量更像“把生成能力做成可交付系统”：桌面代理补安全边界，引擎 UI 与安装链继续工程化。

- **Genex 0.1.45** 把 Antigravity 接入扩到 Windows、Linux，并把 MCP 连接器的 OAuth 账号固定到原授权服务器，撤销请求和跳转也限制在原站点。这对让代理安全调用外部服务、在更多开发机上运行很实用；官方已给多平台安装包、校验和与 SBOM，但仍是早期版本，Windows 包未签名，性能与授权隔离尚未见独立复测。([Release，2026-11-16](https://github.com/genex-games/genex-desktop/releases/tag/v0.1.45))

- **Origin Engine** 把竞技、放置、音游和策略的 23 个界面组件改用共享“角色”与布局原语，删去 232 条组件私有外观声明，同时保留原有状态、动作和部件名。同期还加入由游戏决定计时与结果的快速反应提示，覆盖按键、长按、连按及中途取消测试。对代理生成游戏界面而言，这意味着换主题时不必逐组件改样式，交互契约也更稳定；代码与变更说明已进主分支，但还不是正式发布，我只确认了提交和测试改动，未做视觉回归。([重构提交](https://github.com/originai-game/origin-engine/commit/410b9f4f4e64d7c383813ae93246b24c87f40c8b)、[提示组件](https://github.com/originai-game/origin-engine/commit/93c862b14687318ee8e31d791735c89a8f4fd20e)，2026-11-17)

- **OriEra** 新增 `oriera-sim` 的 PyPI 发布流水线：Linux 轮子经 manylinux 修复，Windows 同步构建，再用 OIDC 可信发布免密上传。它可能把模拟内核从 Rust 工程带进 Python 训练、评测脚本，降低实验接入成本；但仓库明确写着仍需在 PyPI 注册发布者，尚不能把这次提交当成已经上架，更没有可确认的首个安装包。([流水线提交，2026-11-16](https://github.com/OriEra-engine/engine/commit/05245e4303dafa3ee446aef0c236a0aa3e13096f))

我的判断：真正拉开差距的暂时不是“再生成一段玩法”，而是权限、界面契约与分发这些让代理产物能反复运行的基础设施。
