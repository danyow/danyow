# AI 引擎日报｜2026-10-30

今天的新信号不是更大的生成演示，而是两套把“代理如何读、改、跑、查游戏工程”写进架构的早期引擎代码。

## 今日重点

**1. ParallaxEngine 首次公开整套单仓库。** 代码在北京时间10月30日落地，已有类型化 Python SDK、构建/服务/无头测试 CLI，以及开放世界、赛车、MOBA 等32个示例；这让代理可从文本工程到确定性测试走同一条链。现在仍没有根 README 和正式 Release，我也没看到独立构建结果，更适合读代码与试验，不宜当成熟引擎。[初始提交](https://github.com/ParallaxPro-AI/ParallaxEngine/commit/92ffa13c0037ca5973e32e5b75b05ef705704e83)｜[API 文档](https://github.com/ParallaxPro-AI/ParallaxEngine/tree/main/docs/reference)（10-30）

**2. ARP 是本次新发现，不是今天才发布。** 仓库10月29日仍在更新；它把 CLI、MCP、REST 和原生编辑器接到同一命令分发器，资产与界面主要用 YAML，ArpScript 同时提供解释执行和面向本机代码的编译路径。源码与中文说明已公开，但尚无稳定版或可复现的外部验收，WebGPU、WebGL 等也明确标成原型。[仓库](https://github.com/arp-engine/arp)｜[能力矩阵](https://github.com/arp-engine/arp/blob/main/RHI_CAPABILITY_MATRIX.md)（10-29）

**3. ForgeaX 的连续快照开始补“能否可靠跑”。** 10月29日的 `0.5.0-dev.15787` 为 Rapier 2D/3D 暴露全局求解迭代配置，并在重置物理场景前等待刚体同步；发布方称该精确快照通过公开内容筛查和干净安装构建。改动有测试和差异可查，但仍是 `next` 开发通道，不等于稳定发行或独立性能验证。[合并请求](https://github.com/ForgeaX-Games/forgeax-engine/pull/30)（10-29）

## 顺手看

Summer 的 4.9.1 提交让各端应用无需服务器也能导出、上传游戏；功能已进代码，但当前提交文字仍称未发布版本，不能按正式 GitHub Release 计算。[提交](https://github.com/summer-engine/summer/commit/4db10efd9bf4b678a66e4fe42494ab0bfaa4212a)（10-28）

我的判断：代理优先的竞争正从“生成一次”转向可检查的命令、文本资产和自动测试；今天两套新仓库都证明了方向，尚未证明生产成熟度。
