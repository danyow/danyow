电话语音日报

电话语音日报｜2026-09-13

2026-09-13北京时间

今天一句话： 今天最有用的不是又多一个“会说话”的模型，而是几个开源语音框架在补电话链路最容易翻车的地方：断线、重复说话、错误挂断和被打断后的状态。

今天值得看

Pipecat 1.10.0：电话挂断和断线恢复更靠谱

新在哪： 9月12日发布的 1.10.0 修复了 WebSocket 音频被误判“已发送”导致输出队列提前结束的问题；这类错误会让依赖 EndFrame 挂断电话的链路过早结束。Speechmatics 语音识别也加入掉线重连、退避和临时音频缓冲。

离电话助手还差什么： 这让长通话和网络抖动更稳，但不负责挂断后的后台任务、跨通话记忆和主动回拨。

现在能用吗： 已正式发布、代码公开，适合自建电话 Agent 做稳定性升级。

Pipecat v1.10.0 · 09-12

Bolna：连续修复“说重了、卡住了、挂断打不断”

新在哪： 9月11日的 0.10.234 至 0.10.237 连续修了几类真实通话问题：挂断提示可被打断、识别停止产出时释放音频门、内部静音提示不再冒充用户说话、已经播过的轮次不再重新生成。

离电话助手还差什么： 这些修复很贴近全天候电话服务，但仍没有证明跨通话长期任务和个人身份验证已经解决。

现在能用吗： 开源版本可直接研究，值得作为“电话交互层”候选。

Bolna 0.10.237 · 09-11

LiveKit Agents 1.8.1：全双工模型正式进框架

新在哪： 9月10日发布的 1.8.1 新增 DuplexModel，并首先接入 GPT-Live，让 Agent 能在说话时继续听，处理插话与重叠语音；LiveKit 原有电话接入可以与这一层组合。

离电话助手还差什么： 全双工只解决“通话像人”，号码线路、敏感命令确认、挂断后继续执行和回拨仍需外部 Agent 状态机。

现在能用吗： 已发布并有代码；对你要的手机控制 Agent，是比单纯 ASR→LLM→TTS 更接近目标的一步。

LiveKit Agents 1.8.1 · 09-10

顺手看

OpenClaw 2026.9.4 还补了 voice-call 的诊断、取消处理等稳定性修复；国内补漏看到 Flybot 一体机宣称支持 SIP、呼入外呼和企业系统联动，但目前是企业方案，没看到面向个人的开源部署路径。

OpenClaw 2026.9.4 · 09-11 · Flybot 报道 · 09-07

最值得试： 如果先做原型，我会优先验证 OpenClaw/你的现有 Agent + Pipecat 或 LiveKit 的电话层，再把“挂断后继续任务”和二次确认独立做成状态机。
