# 电话语音 Agent 日报｜2026-09-15

**今天一句话：** 今天最值得看的，是 SIP 常驻稳定性继续补洞，同时出现一条更贴近个人自建的路线：直接用自己的 SIM 和 4G 模组让 AI 接打真实蜂窝电话。

### Active Call 0.3.91：SIP 常驻更稳

**新在哪：** 9月14日主分支把版本推进到 0.3.91，SIP OPTIONS 保活加入来源白名单和通话对端自动学习，减少长期暴露时的无关探测；项目本身支持 SIP 呼入外呼、实时插话和 HTTP 工具。**还差什么：** 挂断后长任务、跨通话记忆和自动回拨仍要外接 Agent。**现在能用吗：** MIT 开源、可 Docker 自部署，但大陆个人线路资格仍取决于运营商。
[0.3.91 提交 · 09-14](https://github.com/miuda-ai/active-call/commit/1ff1f3b9cddb062928fb1da1ac42156d4e626cb1) · [项目说明](https://github.com/miuda-ai/active-call)

### CallPilot：自己的 SIM 就是电话入口

**新在哪：** 这是七日补漏，并非今日发布。它用 Quectel EC20/EG25 接真实蜂窝网络，可自动接听、外呼、按 IVR、收发短信和调用工具；Qwen Omni、OpenAI Realtime、豆包均可接，macOS Intel/Rosetta 标为已验证。**还差什么：** 没有大陆运营商兼容矩阵，VoLTE/传统语音取决于 SIM 与运营商，长期任务编排也需另搭。**现在能用吗：** Apache-2.0 开源，作者给出百元级硬件方案。
[项目与中文说明](https://github.com/tianye1999/callpilot) · [0.6.0 说明](https://github.com/tianye1999/callpilot/releases/tag/v0.6.0)

### Duplex Cue：插话不只看“停不停车”

9月11日论文把重叠发言分成继续原话、吸收补充后边说边改、让出话权。作者实验里，真人在协作性插话中更常主动改口，PersonaPlex 明显落后。**实际价值：** 电话助手以后不应只测“会不会被打断”，还要测“有没有听懂插话并修正内容”。论文已公开，但它不是电话栈，也不含工具、记忆和回拨；本次未找到作者代码入口。
[论文 · 09-11](https://arxiv.org/abs/2609.13117)

**最值得试：** 对个人电话入口，CallPilot 的“自有 SIM + 本机 Agent”比继续追云号码更贴近可控性；已有 SIP 则 Active Call 更轻。
